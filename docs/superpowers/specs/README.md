# Diseños (specs)

[Volver al inicio](../../00-inicio.md)

Diseños creados con `superpowers:brainstorming`. Nombre: `YYYY-MM-DD-<tema>-design.md`, con la fecha real de creación.

Cada diseño indica su estado (Propuesto o Aprobado, con fecha). Un diseño Propuesto no autoriza escribir el plan ni implementar. Si incluye frontend, contiene la dirección visual, los tokens y los componentes definidos con ui-ux-pro-max. Además, lista las **pantallas clave** con sus estados (vacío, cargando, con datos, error) y los viewports: esa lista guía las pruebas de capturas de Codex y la revisión visual de Claude.
